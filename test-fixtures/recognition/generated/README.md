# Generated recognition corpus

These deterministic PNG fixtures are project-generated test inputs, released
under CC0-1.0. Their checked-in raster pixels do not depend on fonts installed
on the browser or CI host. They exercise marker, separator, writing-system, layout and
negative-evidence combinations separately from the attributed real-world
corpus. They are not photographs and make no physical-device or population
accuracy claim.

Every image is retained in the repository and pinned by `manifest.json`; the
browser test never downloads fixture bytes.
